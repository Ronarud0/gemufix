# Gemu Luxe Hub

Website portfolio untuk tim Gemu dengan fokus pada tampilan coach, assistant coach, dan manager.

## Fitur Utama
- Tampilan utama menonjolkan **coach**
- Gallery foto kebersamaan tim
- Desain modern dengan nuansa **"young purple"**

## Teknologi
- React + TypeScript
- Vite
- Tailwind CSS
- shadcn/ui

## Instalasi Lokal
```bash
git clone https://github.com/Ronarud0/gemu.git
cd gemu
npm install
npm run dev
